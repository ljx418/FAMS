# FAMS 每日持仓复盘 PRD

版本：1.0  
状态：产品化工作台已实现，真实数据自动功能验收通过，人工验收未执行  
更新时间：2026-08-21

## 1. 产品目标

用户在开盘后、收盘前或任意时点通过 FAMS ChatBox 发起持仓复盘。系统读取当前持仓和已确认截图数据，取得最新价格及最近 30 个完整交易日收盘价，计算 MA5、MA10、MA30，比较上一轮基本面、消息面、策略和网格变化，并生成可供用户手工设置的研究级买卖网格。

本功能不连接券商下单接口，不创建订单，不解锁正式交易。

## 2. 用户主流程

1. 用户在 ChatBox 选择“生成当前持仓复盘”，确认后启动审计 Operation。
2. 系统逐个处理非现金持仓；单个资产失败不得拖垮整个组合。
3. ChatBox 展示价格、来源时间、MA 数值、30 日曲线、事实变化、策略判断、关注标的和人工计划网格。
4. 用户可以打开历史复盘，比较此前保存的持仓、行情和网格快照。
5. 用户上传证券截图时，系统先私有保存；经单次视觉处理同意后识别，用户可逐字段修正、忽略或确认。

### 2.1 产品化工作台

除 ChatBox 主入口外，系统提供 `/daily-reviews` 与 `/daily-reviews/:reviewId` 工作台，用于审查已经生成的复盘和启动新的受控复盘。工作台固定展示十个公开审计节点：触发、持仓快照、行情采集、均线计算、基本面与消息、策略评估、关注标的、系统网格、历史比较和执行边界。

节点只展示运行输入、可核查输出、证据引用、数据来源、阻断条件和用户本地验收备注，不展示或保存模型私密思维链。任何由报告派生的展示必须标记为 `derived_view`，不得冒充原始运行记录。

## 3. 功能需求

| 编号 | 要求 | 验收结果 |
| --- | --- | --- |
| DPR-001 | 支持 `open`、`pre_close`、`manual` 三种场次；ChatBox 手动触发是默认主入口。 | 生成独立运行记录，并支持幂等键。 |
| DPR-002 | 读取当前开放持仓和已确认截图台账；截图缺失持仓只提示差异。 | 不自动减少、关闭或删除任何缺失持仓。 |
| DPR-003 | 每个非现金资产展示最新价、来源、时间、最近30个完整收盘价及 MA5/10/30。 | 图表固定包含收盘价与三条均线；不足时明确降级。 |
| DPR-004 | 比较本轮与上一轮基本面、消息事件和证据。 | 输出 `none/watch/material/insufficient`、理由及 evidenceRefs。 |
| DPR-005 | 输出组合策略总体判断。 | 只允许 `maintain/needs_review/evidence_insufficient`，不把缺证据解释成利好。 |
| DPR-006 | 输出需要关注的持仓和红利低波候选池标的。 | 每项标明来源、原因和证据状态，不形成必买清单。 |
| DPR-007 | 输出版本化人工计划网格并比较上一轮。 | 已验证个人策略优先；无个人策略时使用内置研究模板；条件不足转观察。 |
| DPR-008 | 保存并查询运行、持仓快照、行情快照、网格方案和建议。 | 支持分页、场次和状态过滤；历史结果可回看。 |
| DPR-009 | 支持截图上传、单次视觉同意、纠错、忽略和逐行确认。 | 原识别值和纠错记录可追溯；已确认行不可修改。 |
| DPR-010 | 固定执行隔离。 | 所有结果保持交易权限为 false，任何路径都不得创建券商订单。 |

## 4. 网格规则

- 已激活且验证通过的用户网格策略优先。
- 没有适用个人策略时：股票、ETF、普通基金使用 `mean_reversion_atr_v1`；黄金、债券和债基使用 `cost_support_v1`。
- 研究兜底模板不创建、不激活策略版本，`strategyVersionId=null`，并标记 `strategySource=system_research_fallback`。
- 历史样本、行情置信度、现金、持仓数量、重大变化或外部委托冲突不满足要求时，输出观察或冲突提示，不伪造数量。
- 网格记录价格、数量、档位、理由、有效期和相较上一轮的变化，始终标记为人工计划草案。

## 5. 截图与隐私

- 只接受真实 PNG、JPEG、WebP，单文件最大 10MB；使用 SHA-256 去重并保存到私有目录。
- 视觉模型必须通过 `FAMS_VISION_*` 明确配置，且每次发送前单独取得用户同意。
- 未配置模型时仍可私有保存，并允许 Codex或人工提交结构化字段。
- 确认前允许逐字段修正或忽略；修改会重新执行字段校验、资产匹配和持仓差异计算。
- 委托截图只生成外部委托观察，用于网格冲突检查，不生成新订单。

## 6. 数据与安全边界

每日复盘复用本地 canonical market bars、行情服务、PositionAdvice/FIVD-R 事实集、红利低波候选池及现有 Prisma 快照表。数据不足或 provider 失败必须进入 `partial/insufficient`，不得生成未经证据支持的确定性结论。

固定字段：

```text
formalTradingUnlocked=false
autoTradeUnlocked=false
canCreateOrder=false
orderCreateAllowed=false
```

允许动作只有研究、观察、比较、提醒和人工计划草案。

## 7. 非本期范围

- 生产券商适配器、订单创建、自动交易。

## 8. 出门标准

- 追踪矩阵中的 DPR-001～DPR-010 均有实现和自动化证据。
- FIVD-R 组合接口真实运行返回 HTTP 200；单资产失败返回组合 `partial`。
- 后端、前端构建和每日复盘专项测试通过。
- 低风险产品功能使用真实账户、真实行情、真实历史快照和真实浏览器完成自动化功能验收；夹具化测试不能代替真实数据证据。
- `daily-portfolio-review-human-checklist.html` 保留为可选人工复核入口。未执行时必须记录 `humanAcceptanceStatus=not_performed`，不得伪造人工验收结论。
- 自动验收允许 PRD 已定义的 `partial` 降级，但必须逐项显示失败资产和原因，且至少一个真实资产成功；全资产失败不能出门。
- 每个产品化子阶段必须分别落盘开发计划、开发前审计、验收审计和 PRD 规格检视；存在未关闭致命或重大意见时不得进入下一阶段。
