# FAMS 每日持仓复盘 PRD

版本：1.4
状态：1.4 已实现；新增版本化支付宝分析工作流、持久化组合研究与滑动窗口双口径比较；人工验收未执行
更新时间：2026-09-06

## 1. 产品目标

用户在开盘后、收盘前或任意时点通过 FAMS ChatBox 发起持仓复盘。系统读取当前持仓和已确认截图数据，取得最新价格及最近 30 个完整交易日收盘价，计算 MA5、MA10、MA30，比较上一轮基本面、消息面、策略和网格变化，并生成可供用户手工设置的研究级买卖网格。

本功能不连接券商下单接口，不创建订单，不解锁正式交易。

## 2. 用户主流程

1. 用户在 ChatBox 选择“生成当前持仓复盘”，确认后启动审计 Operation。
2. 系统逐个处理非现金持仓；单个资产失败不得拖垮整个组合。
3. ChatBox 展示价格、来源时间、MA 数值、30 日曲线、事实变化、策略判断、关注标的和人工计划网格。
4. 用户可以打开历史复盘，比较此前保存的持仓、行情和网格快照。
5. 用户上传证券截图时，系统先私有保存；经单次视觉处理同意后识别，用户可逐字段修正、忽略或确认。

### 2.1 产品化工作台

除 ChatBox 主入口外，系统提供 `/daily-reviews` 与 `/daily-reviews/:reviewId` 工作台，用于审查已经生成的复盘和启动新的受控复盘。工作台固定展示十个公开审计节点：触发、持仓快照、行情采集、均线计算、基本面与消息、策略评估、关注标的、系统网格、历史比较和执行边界。

十个节点组成具有显式依赖边的有向无环图。单击节点高亮上下游路径；双击或使用 Enter/Space 打开的节点弹窗只展示该节点作用、输入和输出。证据引用、数据来源、阻断条件和用户本地验收备注统一位于“高级审计”抽屉。页面不展示或保存模型私密思维链；任何由报告派生的展示必须标记为 `derived_view`，不得冒充原始运行记录。

### 2.2 支付宝一键固定工作流

每日复盘页提供不依赖 ChatBox 的支付宝入口。用户先声明最近确认截图后持仓是否变化；无变化可复用快照，有变化但未确认新截图必须阻断。系统以已确认账户总额和总额型基金持仓为当前仓位权威，以基金交易/分红流水作历史约束，刷新最近完整交易日的净值、MA 与周频 RRG，再按已批准 5/25/25/45 配置生成第一批金额草案。严格 LLM 仅整理白名单事实，失败时整轮失败。

用户可在页面逐项接受、修改或拒绝人工计划。决定只进入 AdviceExecution/AdviceAction 审计记录，`executedAt=null`；不得生成 Transaction、修改 Position 或创建外部订单。赎回资格或费用未知的减持项禁止接受/修改。

### 2.3 固定分析入口、定时运行与滑动窗口

`/portfolio-comparison` 是不依赖 ChatBox 的固定入口。工作流合同必须版本化保存，并明确分离两套用途：已经批准的现金/黄金/债券/权益 `5/25/25/45` 只生成手工调仓草案；`10/25/40/25` 只用于历史研究比较，不能升级为当日交易指令。一次“完整分析”依次执行截图前检、行情与 MA/RRG 刷新、持仓和历史交易约束、实际配置草案、十组组合对比、严格 LLM 摘要及持久化。

用户可授权系统在七天内复用当前最新的已确认支付宝持仓截图。授权到期、撤销或出现更新截图时，定时运行和未显式声明持仓变化的手动运行必须阻断。工作日定时运行默认关闭；启用后按 Asia/Shanghai 的一至两个时间槽触发，默认 `09:40` 和 `14:40`，并使用租约与幂等键防止同一时间槽重复运行。

每次组合比较必须保存完整数据快照、数据哈希、规则、曲线、交易事件、指标和摘要。历史报告读取保存结果，不得隐式重新抓取行情。报告内滑动窗口同时显示：一是保留窗口开始日前仓位和触发状态的“连续路径切片”；二是使用相同冻结规则在窗口首日重新建仓的“窗口重启”。两种口径共享同一运行的数据快照，最少二十个共同交易日；不足 252 日时必须提示年化指标对起止日期敏感。

## 4. 网格规则

- 已激活且验证通过的用户网格策略优先。
- 没有适用个人策略时：股票、ETF、普通基金使用 `mean_reversion_atr_v1`；黄金、债券和债基使用 `cost_support_v1`。
- 研究兜底模板不创建、不激活策略版本，`strategyVersionId=null`，并标记 `strategySource=system_research_fallback`。
- 历史样本、行情置信度、现金、持仓数量、重大变化、个股估值风险或外部委托冲突不满足要求时，输出观察或冲突提示，不伪造数量。
- 基本面/消息证据不足属于全局门禁；重大变化与个股估值风险只禁止新增买入，证据充分且数量满足约束时可保留风险降低型卖出草案。
- 每个网格保存技术锚来源、ATR 原始/裁剪后间距、现金与仓位容量、整手约束、分侧门禁和最终订单，供页面独立复算。
- 网格记录价格、数量、档位、理由、有效期和相较上一轮的变化，始终标记为人工计划草案。
- 独立网格与条件买回网格分别持久化；条件买回价由父卖价下移一个本轮最终网格间距生成，数量不得超过父卖单数量。
- 价格按证券类型的最小变动单位做方向性取整：买入向下、卖出向上；数量使用整手最大余数分配，避免可交易总量被逐档取整为零。
- 即时买单共享同一个组合级预算；条件买回在父卖单成交前不计入即时预算。
- `session_close` 草案在生成当日 15:00（Asia/Shanghai）失效；收盘后生成的报告只允许观察，不产生仍有效的当日草案。

## 4.1 一次性 LLM 汇总边界

- LLM 输入是确定性报告的最小白名单投影，不直接参与行情、均线、估值、网格、价格或数量计算。
- 每个新复盘最多一次汇总请求；结果或降级摘要随 `reportJson` 固化，任何读取页面均不得重新请求模型。
- 输出必须通过严格结构、标的白名单和证据引用子集校验；叙述不得新增数值、目标价、订单或事实。
- LLM 未配置、供应商失败、超时或校验失败时，保存 `fallback`、尝试次数和脱敏失败码，确定性订单清单继续可用。
- 当运行请求显式设置 `requireLlmSuccess=true` 时，`fallback` 只能保存为失败证据，复盘状态必须为 `failed`，不得通过本轮验收。

## 5. 截图与隐私

- 只接受真实 PNG、JPEG、WebP，单文件最大 10MB；使用 SHA-256 去重并保存到私有目录。
- 视觉模型必须通过 `FAMS_VISION_*` 明确配置，且每次发送前单独取得用户同意。
- 未配置模型时仍可私有保存，并允许 Codex或人工提交结构化字段。
- 确认前允许逐字段修正或忽略；修改会重新执行字段校验、资产匹配和持仓差异计算。
- 委托截图只生成外部委托观察，用于网格冲突检查，不生成新订单。
- 账户摘要使用 `account_summary` 行保存资金余额、可用金额、股票市值、总资产和盈亏；该行不要求匹配证券资产。
- 现金仓以截图可用金额为网格预算；页眉股票市值与逐行合计不一致时保留差额告警，不以页眉反向篡改持仓明细。

## 6. 数据与安全边界

每日复盘复用本地 canonical market bars、行情服务、PositionAdvice/FIVD-R 事实集、红利低波候选池及现有 Prisma 快照表。数据不足或 provider 失败必须进入 `partial/insufficient`，不得生成未经证据支持的确定性结论。

固定字段：

```text
formalTradingUnlocked=false
autoTradeUnlocked=false
canCreateOrder=false
orderCreateAllowed=false
```

允许动作只有研究、观察、比较、提醒和人工计划草案。

## 7. 非本期范围

- 正式 provider 授权、官方 benchmark、formal validation 人工统计复核和正式发布签核。
- 生产券商适配器、订单创建、自动交易。
- V2-PX 草案需求。

## 8. 出门标准

- 追踪矩阵中的 DPR-001～DPR-030 均有实现和自动化证据；数据库或外部供应商故障导致真实验收中断时，状态必须保持 blocked/conditional，不得沿用旧轮验收冒充新规格验收。
- FIVD-R 组合接口真实运行返回 HTTP 200；单资产失败返回组合 `partial`。
- 后端、前端构建和每日复盘专项测试通过。
- 低风险产品功能使用真实账户、真实行情、真实历史快照和真实浏览器完成自动化功能验收；夹具化测试不能代替真实数据证据。
- `daily-portfolio-review-human-checklist.html` 保留为可选人工复核入口。未执行时必须记录 `humanAcceptanceStatus=not_performed`，不得伪造人工验收结论。
- 自动验收允许 PRD 已定义的 `partial` 降级，但必须逐项显示失败资产和原因，且至少一个真实资产成功；全资产失败不能出门。
- 每个产品化子阶段必须分别落盘开发计划、开发前审计、验收审计和 PRD 规格检视；存在未关闭致命或重大意见时不得进入下一阶段。
