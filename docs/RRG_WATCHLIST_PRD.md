# RRG 多市场自选与显示管理 PRD

状态：V1 已实现
更新时间：2026-08-27

## 1. 目标与边界

在“相对轮动与波动仓”页面中，把当前持仓和用户自选组成统一 RRG 观察池。持仓默认展示；用户可输入市场与证券代码增加其他标的，并在前端控制显示或隐藏。

本功能只用于研究与波动仓证据展示，不发送券商订单，不把样本不足的标的伪装成有效 RRG 坐标，也不因删除自选而删除真实持仓或全项目共享行情。

## 2. 产品规格

| ID | 规格 | 验收标准 |
| --- | --- | --- |
| RRG-WL-001 | 支持 A股、港股、美股市场 + 代码输入 | A股接受6位代码及 `.SH/.SZ/.BJ`；港股规范为5位 + `.HK`；美股规范为大写 ticker；非法代码被拒绝 |
| RRG-WL-002 | 持仓默认展示 | 当前市场全部开放股票/ETF持仓自动进入观察池，不需要写入自选表 |
| RRG-WL-003 | 自选列表 | 新增幂等；每用户最多30个；同一标的兼具持仓与自选时只显示一条并展示两个来源标签 |
| RRG-WL-004 | 显示/隐藏 | 显隐只保存在浏览器本地；隐藏项不绘图、不参加自动刷新；重新显示老化项时自动刷新 |
| RRG-WL-005 | 数据老化 | 以同市场基准交易日为准：滞后0日为最新、1日为延迟、2日及以上为已老化、缺少可比日期为待校验；页面显示截止日、样本数与状态 |
| RRG-WL-006 | 删除语义 | 删除自选时级联删除该用户该标的的 RRG 序列、节点和刷新记录；保留共享标准行情、其他用户数据和真实持仓 |
| RRG-WL-007 | 多市场基准 | A股=沪深300 `000300.SH`；港股=恒生指数 `^HSI`；美股=标普500 `^GSPC`；不同市场禁止混图比较 |
| RRG-WL-008 | 价格口径 | A股资产使用前复权 qfq；港美股优先调整收盘价，备用源做可识别拆并股连续化；指数使用价格指数且不复权 |
| RRG-WL-009 | 样本门槛 | 公式最低门槛为日频91个对齐交易日、周频53个对齐周；至少756个资产和基准交易日才标为“验证充分”；不足时展示阻断原因且不造点 |
| RRG-WL-010 | 真实来源与降级 | 优先智能/高质量行情；港美股 Yahoo 不可用时分别降级到腾讯港股、新浪美股；单源与备用连续化必须显示警告 |
| RRG-WL-011 | 正式验证自选 | 默认用户保留 `515070` 人工智能AI ETF、`512480` 半导体ETF、`688825` 长鑫科技作为正式验证集 |
| RRG-WL-012 | 交互与可访问性 | 市场切换、显隐、单项刷新、删除确认、空状态、加载态均可操作；关键控件有可读标签；图表区分有限历史和老化数据 |

## 3. 数据与接口

用户专属数据：`RelativeRotationWatchlistItem`、`RelativeRotationWatchlistSeries`、`RelativeRotationWatchlistPoint`、`RelativeRotationWatchlistRefreshRun`。共享数据继续使用 `MarketBarRaw`、`MarketBarCanonical`、`MarketDataCoverage`。

| 方法与路由 | 责任 |
| --- | --- |
| `GET /api/v1/relative-rotation/watchlist` | 返回当前用户自选和序列健康状态 |
| `POST /api/v1/relative-rotation/watchlist` | 规范化、校验、幂等新增并可立即刷新 |
| `DELETE /api/v1/relative-rotation/watchlist/:itemId` | 删除用户专属 RRG 数据并返回保留/删除计数 |
| `GET /api/v1/relative-rotation/universe/timeline` | 按市场合并持仓与自选，返回可追溯 RRG 时间线 |
| `POST /api/v1/relative-rotation/universe/refresh` | 只刷新指定可见目标，返回逐标的结果 |

## 4. V1 验证结论

- `515070`：1619 个真实交易日，日/周频均“验证充分”。
- `512480`：1751 个真实交易日，日/周频均“验证充分”。
- `688825`：24 个真实交易日，日/周频均“样本不足”，无伪造坐标。
- 港股真实样例 `00700.HK` 与恒生指数：各1040个交易日，可生成180个周频、959个日频节点。
- 美股真实样例 `AAPL` 与标普500：各1040个交易日，可生成176个周频、961个日频节点。

以上数量来自 2026-08-27 本地标准行情库的正式验收运行；后续行情刷新会改变实际条数和截止日期。
