# DRV1-9 开发计划：账户摘要截图与全量对账

日期：2026-08-25（Asia/Shanghai）

## 验收标准

1. 截图协议支持不绑定资产的 `account_summary` 行，并保存资金余额、可用金额、股票市值、总资产与盈亏字段。
2. 2026-08-25 截图确认后，六个证券数量与截图一致，现金与截图可用金额精确一致；不新增、不关闭持仓。精确账户金额只写入本地私有证据。
3. 截图成本与现有高精度成本按显示精度相等时保留原精度。
4. 明细市值与页眉市值的非零差额必须留痕，不得静默抹平；精确金额只写入本地私有证据。
5. Transaction、ExternalOrderObservation 和券商订单边界不发生变化。

## 实现步骤

1. 更新 PRD 与追踪矩阵，冻结字段、精度和差额口径。
2. 扩展截图校验、预览、纠错和确认服务；现金确认复用现有 cash Position。
3. 扩展共享截图面板，展示账户摘要与组合对账告警。
4. 运行夹具契约和真实截图确认前后差异验收。

## 打回条件

任何自动关闭持仓、成本精度下降、页眉差额消失、现金不等于可用金额或交易表漂移均打回开发阶段。
