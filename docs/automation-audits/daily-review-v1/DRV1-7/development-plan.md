# DRV1-7 DAG 与结论工作台开发计划

日期：2026-08-21

## 目标

- 使用本地 HTML/SVG 实现有连线的十节点 DAG，不新增图形依赖。
- 双击节点弹窗仅显示作用、输入和输出；证据与本地审阅迁移到高级审计抽屉。
- 新增结论摘要、人工计划设置清单、关注标的 LLM 解读和逐标的规则推导链。

## 验收标准

- 桌面、紧凑桌面、平板、手机均不产生根页面横向溢出；DAG 可在内部平移。
- 鼠标双击与键盘 Enter/Space 均可打开节点弹窗，弹窗不存在证据或阻断内容。
- 单击仅高亮上下游路径；高级审计抽屉保留全部证据、阻断和本地审阅。
- 关注卡正文不展示原始 evidence id；原始 id 仅在审计抽屉中可见。
- 人工设置清单和推导链逐项等于后端确定性结果，四项执行锁持续可见。

## 实施顺序

1. 拆分 DagCanvas、NodeDetailModal、AuditDrawer、DecisionSummary、OrderPlan、DerivationTrace 组件。
2. 重排 DailyReviews 信息层级并兼容历史报告。
3. 更新 Playwright 真实浏览器验收、导出和无障碍断言。
4. 更新 PRD、追踪矩阵、使用说明和阶段审计。
