# DRV1-10 开发前审计

日期：2026-08-25（Asia/Shanghai）

## 规范与基线

- 上交所交易规则的当前公开文本规定 A 股申报价格最小变动单位 0.01 元、基金 0.001 元，竞价买入为 100 股/份或其整数倍。
- 深交所投资者教育公开规则规定基金申报价格最小变动单位 0.001 元，竞价买入为 100 份或其整数倍。
- 当前引擎统一保留四位小数、逐档向下取整数量、每个资产各自重复计算现金预算，有价格不合法、小仓位卖出档位消失和组合超配风险。
- 当前每项资产只持久化一份即时 GridPlan，没有父卖单条件买回合同。

## 审计意见与闭环设计

1. **重大：市场步长不合规。** 由资产类型和中国市场明确解析 tick；买卖按方向取整，结果再做整数 tick 断言。
2. **重大：逐档取整损失可交易数量。** 总数量先换算整手数，再按权重最大余数分配；至少一手时不得因档数多而全部归零。
3. **重大：组合现金被按资产重复使用。** 运行内维护唯一 `remainingImmediateBuyBudget`，每项资产只能使用剩余额度，按已保存即时买单金额扣减。
4. **重大：条件买回可能被误当即时单。** 单独 GridPlan、单独状态、仅保存 `awaiting_parent_fill`；即时预算与即时清单明确排除。
5. **重大：父子条件缺少可核对锚。** 先持久化父卖单，再以其数据库 ID 构建子草案，触发 JSON 保存父计划、父单、成交数量与激活策略。
6. **重大：有效期可能跨收盘。** 所有草案统一以生成当日上海时间 15:00 为上限，收盘后全局阻断。
7. **重大：历史链会在双计划间错配。** 即时查询排除 `conditional_buyback`，条件查询只接受该 mode。

## 准入结论

七项重大意见均有确定性、可自动化验证的闭环设计；无新增致命意见，允许进入 DRV1-10 实质开发。该阶段仍只生成研究级人工计划草案。
