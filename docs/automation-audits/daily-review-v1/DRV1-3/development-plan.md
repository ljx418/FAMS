# DRV1-3 开发计划：截图台账与人工审阅闭环

日期：2026-08-20  
状态：已完成

## 目标

将既有 ChatBox 截图导入流程抽成正式共享组件，并在每日复盘工作台复用；增加按复盘/节点保存的本地人工审阅标注，完成隐私、响应式和无障碍闭环。

## 交付范围

1. `ScreenshotCapturePanel`：PNG/JPEG/WebP、10MB 校验、私有保存、逐次视觉同意、预览、字段修正、忽略、确认。
2. ChatBox 与每日复盘工作台调用同一组件和同一后端接口；确认后通知宿主刷新。
3. 节点审阅状态 `pending/pass/issue` 和备注按 `reviewId + nodeId` 存在浏览器 localStorage，并进入导出 JSON。
4. 手机/平板/桌面操作、键盘语义和错误反馈可用。

## 禁止项

- 不自动勾选视觉同意，不在未同意时发给外部模型。
- 不暴露截图 storagePath、密钥或模型私密思维链。
- 不因截图缺失而关闭持仓，不生成券商订单。
- 本地节点标注不是正式发布签核，不得伪装成人工验收完成。

## 出门标准

- 前后端构建和截图前端合同通过。
- 共享组件在 ChatBox 与工作台均可操作。
- 使用既有真实确认截图验证汇总；自动化流程不得重复向视觉模型发送该截图。
- 390/768/1440 三档无文档根溢出；按钮、输入和状态有可识别标签。
- 审阅标注刷新后恢复，切换 review/node 不串数据，导出包含标注。
