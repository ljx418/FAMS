## 审计意见闭环

| 级别 | 意见 | 处理 |
| --- | --- | --- |
| 重大（已关闭） | 原型包含冻结数据，复制原型 JS 会形成虚假实时页面。 | 只移植信息架构和样式语言，所有业务值从正式 API 读取。 |
| 重大（已关闭） | “运行复盘”会写入真实快照，误触风险高于普通查询。 | 按钮先弹确认；生成唯一幂等键；页面明确列出允许写入对象。 |
| 一般（已关闭） | 深链刷新可能丢失选中运行。 | 使用路由参数作为唯一选中源，并在不存在时回退最新记录。 |
| 一般（已关闭） | 关注项证据和系统网格易被理解成必买单。 | 独立显示证据状态、策略来源、阻断项和“人工计划草案”标签。 |
