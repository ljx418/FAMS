# DRV1-5 开发前审计

日期：2026-08-21  
结论：`pass_with_controls`

## 基线事实

- 当前 DailyReviewService 使用浅层 PositionAdvice 缓存，已观察到深度事实存在但策略节点未纳入的风险。
- 当前网格以 MA10 等技术值为锚，没有公允价值目标价模型。
- 当前 `blockBuyOnMaterialChange` 的实现会阻断双向订单，与字段语义不一致。
- 当前工作流仅有有序节点数组，无显式依赖边。

## 审计意见与闭环

- 重大：不得把估值评分转换为未经验证的目标价。闭环：只保存价值评估基线，订单价格继续由技术锚确定。
- 重大：证据不足不得生成确定性订单。闭环：证据不足列为全局门禁。
- 重大：重大变化必须阻止加仓。闭环：改为买侧门禁，并允许证据充分时生成风险降低型卖出草案。
- 一般：新增字段必须兼容历史 v1 报告。闭环：所有 v2 字段在前端和读取层均提供 legacy fallback。

未发现未闭环致命或重大风险，允许进入开发。
