# DRV1-6 一次性 LLM 证据汇总开发计划

日期：2026-08-21

## 目标

- 每轮复盘完成确定性计算后，对全组合执行一次 LLM 汇总并写入 reportJson。
- LLM 只解释关注标的和已保存订单，不创造事实、标的、订单或目标价。
- LLM 不可用、超时、格式错误或越权时保存规则降级摘要。

## 验收标准

- 每轮新复盘最多一次 LLM 请求；GET、刷新与导出不触发 LLM。
- 输出通过结构校验、标的白名单、证据引用子集和订单价格/数量一致性校验。
- 非法输出不进入页面，状态为 `fallback` 并记录脱敏失败码。
- 页面能够区分 `llm`、`deterministic` 与历史 `legacy_missing`。

## 实施顺序

1. 复用 FAMS LLM 配置和 pi-ai 创建 DailyReviewSynthesisService。
2. 建立最小证据投影、结构校验和确定性 fallback。
3. 在复盘保存前调用一次，并将调用元数据写入报告。
4. 增加成功、超时、非法引用、篡改订单和未配置测试。
