## 2. 体验原则

1. Side Panel 只回答“当前任务是什么、结论是什么、是否可信、下一步做什么”。
2. Workspace Page 才展示完整来源、图表、追踪、关系图和高级证据。
3. 普通用户默认看到简短摘要，高级字段放入证据抽屉。
4. 未连接、加载、空、失败和恢复状态必须有独立界面，禁止用空白页或原始异常代替。
5. 所有投资内容保持研究与人工计划草案定位，不展示“立即买入”“创建订单”等动作。

## 3. Side Panel：360 / 420px

目标线框：

```text
┌──────────────────────────────┐
│ FAMS 外部大脑      ● 已连接 │
├──────────────────────────────┤
│ 当前任务                     │
│ 600276 每日复盘              │
│ 数据截至 14:32 · 研究模式    │
├──────────────────────────────┤
│ 简明结论                     │
│ 基本面暂无本质变化；价格位于 │
│ MA10 附近，网格暂不扩大。    │
│ [查看依据]                   │
├──────────────────────────────┤
│ [在完整工作台打开]           │
├──────────────────────────────┤
│ 向外部大脑提问…              │
│ [发送]                       │
├──────────────────────────────┤
│ 最近任务：复盘 / RRG / 来源  │
└──────────────────────────────┘
```

Side Panel 必须具备：

- 连接状态与最后同步时间。
- 当前 workspace 标题、研究模式和数据时间。
- 最多 5 行简明结论；超出内容进入 Workspace。
- `查看依据`、`在完整工作台打开` 两个明确动作。
- 最近任务列表最多 5 条。
- 360px 无横向滚动；主要点击区域高度至少 44px。
- 提交问题后 1 秒内显示“已接收/正在处理”；最终摘要与接收态分开，不把 skeleton 或 ack 冒充答案。

Side Panel 禁止：

- 完整 K 线或复杂 DAG。
- 原始 artifactRefs 列表常驻首屏。
- 大型表格和超过两层的折叠结构。
- 订单、自动交易或交易解锁按钮。

## 4. Workspace Page：768 / 1280px

目标线框：

```text
┌──────────────────────────────────────────────────────────────┐
│ FAMS External Brain │ 工作区：600276复盘 │ 已恢复 │ 研究模式 │
├──────────────┬───────────────────────────────────────────────┤
│ 来源库       │ 结论摘要                                      │
│ 问答         │ - 当前判断                                    │
│ 追踪         │ - 关键依据                                    │
│ 图谱         │ - 风险与下一步                                │
│              ├───────────────────────────────────────────────┤
│ 最近任务     │ 主内容：来源详情 / 问答 / 时间线 / DAG / 图表 │
│              │                                               │
│              ├───────────────────────────────────────────────┤
│              │ [证据与数据状态] 折叠抽屉                     │
└──────────────┴───────────────────────────────────────────────┘
```

1280px 使用左侧导航 + 主内容；768px 导航折叠为 Drawer，但核心摘要和当前视图必须保持可见。完整工作台包含：

- 工作区身份和恢复状态。
- 五类 intent 导航。
- 普通话结论摘要。
- 与 intent 对应的主内容。
- 来源、时间、新鲜度和关联 operation。
- 默认折叠的证据抽屉。
- 明确的失败恢复动作。

## 5. 五类视图设计

| View | 默认显示 | 高级详情 | 空/失败处理 |
| --- | --- | --- | --- |
| 来源库 | 类型、标题、时间、可信状态 | sourceRef、artifactRef、operationId | 无来源时解释如何运行复盘或研究任务 |
| 来源详情 | 摘要、来源、截至时间、关联任务 | 原始字段和证据链 | 来源删除时保留引用并显示不可用 |
| 问答 | 简明结论、依据、风险、下一步 | 结构化结果、模型/数据状态 | 进入 Ask View 不等于提交问题；LLM 不可用时显示确定性 fallback |
| 追踪 | 任务状态、阶段、耗时、下一步 | Operation task、错误和 artifact | 任务不存在时允许回到来源库 |
| 图谱 | 复盘 DAG 或 evidence 关系 | 节点输入输出和依赖 | 无图谱时说明该任务不支持图谱 |

## 6. 状态矩阵

| 状态 | Side Panel | Workspace Page | 可执行动作 |
| --- | --- | --- | --- |
| 未连接 | 权限用途 + 连接按钮 | 连接说明，不展示伪数据 | 连接、查看隐私说明 |
| 加载 | skeleton + 当前任务名 | 保留框架和上次视图标记 | 取消、等待 |
| 正常 | 简明摘要 + 打开工作台 | 完整五视图 | 查看、切换、刷新只读数据 |
| 空 | 说明为何为空 | 建议运行现有 FAMS 任务 | 打开 FAMS 对应页面 |
| 失败 | 简短原因 + 重试 | RecoveryBanner + 诊断折叠 | 重试、回到最近可用状态 |
| 恢复中 | “正在恢复上次任务” | 显示恢复步骤 | 取消恢复 |
| 已阻断 | 清晰阻断原因 | 证据和恢复条件 | 不显示成功或交易动作 |

## 7. 三入口动作

| 入口 | 查看来源 | 打开工作台 | 在工作台中打开 |
| --- | --- | --- | --- |
| Side Panel | 当前面板显示来源摘要 | 打开/复用最近 workspace | 将当前 source/operation 定位到 Workspace |
| Workspace Page | 在主区原地切换来源详情 | 聚焦当前 workspace | 定位目标 view，不新建重复 tab |
| FAMS Host App | 打开/复用 Workspace 来源详情 | 打开/复用 workspace | 携带当前 review/operation/source 上下文定位 |

三入口传递同一业务对象时，`workspaceId / canonicalRouteKey / correlationId` 的语义必须一致；允许新的操作生成新 `routeId`，但不能丢失关联链。Host App 不以自动唤起 Side Panel 为正确性前提；Chrome 能力不支持时必须可靠进入 Workspace。Intent route 只负责进入 Ask View，问题正文由扩展内部 operation command 提交。

## 8. 可视性和可访问性门槛

- 正文默认字号不低于 14px，关键摘要建议 16px。
- 正文文字与背景对比度至少 4.5:1。
- 可点击目标至少 44×44px。
- 360、420、768、1280 四视口根节点 `scrollWidth <= clientWidth`。
- Tab 键可以到达连接、发送、打开工作台、导航和恢复动作。
- focus-visible 清晰；不能只用颜色表示成功、失败或阻断。
- loading、empty、error、blocked 都有可读文本。

## 9. 原型验收步骤

1. 打开 360px Side Panel，确认首屏无需横向滚动即可看到连接状态、摘要和打开工作台按钮。
2. 从 Side Panel 打开 Workspace，确认 1280px 显示五类导航、摘要、主内容和证据抽屉。
3. 切换至 768px，确认导航折叠但主内容不被遮挡。
4. 分别触发未连接、加载、空、失败、恢复和阻断状态，确认每种状态有原因和下一步。
5. 连续点击三次打开工作台，目标体验必须是聚焦同一标签页。
6. 检查任何页面均没有创建订单、自动交易或交易解锁动作。
7. 从 Host App 点击“查看来源”，确认进入 Workspace 来源详情；关闭扩展或清空 extension ID 后确认出现普通话配置说明。
8. 在 Ask View 只导航不发送问题；只有点击发送才产生一个 query command，同 key 重放不产生第二次请求。

本文通过只表示目标原型足以指导实现。真实交互、截图、trace 和 lifecycle event 必须等用户批准后由 PX-1+ 在真实 Chrome 中生成。
