1. 目标体验说清楚

UX-F7 不是单纯换颜色。它要把普通用户主路径、资深用户专家路径和交易边界同时说清楚。

普通用户体验

打开系统先看到 ChatBox 任务入口和工作台摘要，可以导入资产、对比组合、查看红利低波和任务状态，不需要先理解复杂表格。

资深用户体验

左侧菜单和专家多 Tab 保留，Backtest、DividendLowVol、Operations、Analysis 等页面继续提供完整筛选、参数、证据和审计入口。

交易边界体验

所有页面和 ChatBox 都必须解释：当前只支持研究、观察、比较和人工计划草案；正式买卖、订单创建和自动交易仍锁定。

7. 开发与验收映射

下一阶段代码实现必须逐项拿截图、测试和审计 JSON 证明完成，不能只提交视觉改色。

统一视觉系统Dashboard、Assets、DividendLowVol、Backtest、Operations、ChatBox 使用同一 token、卡片、按钮、标签、表格样式。`frontend_visual_system_audit.json` + 桌面/平板/移动截图。页面无明显色块断层，状态色数量受控，对比度抽样通过。
卡片按压反馈所有可点击卡片和行动按钮有 hover、active pressed、focus-visible、disabled、loading、empty 状态。组件状态截图 + 键盘焦点检查。按压有力感但不跳动，移动端触摸反馈可见。
资产 Excel模板下载、上传预览、错误校验、确认导入、导出当前资产。`asset_excel_flow_audit.json` + 导出工作簿结构。导出至少含当前持仓、交易记录、字段说明；导入不创建订单。
Dashboard 密度与图标核心卡片有开源图标，空状态指向导入资产或 ChatBox，首屏减少无效空白。`dashboard_visual_density_audit.json` + 1440/768/390 截图。普通用户能在首屏理解下一步。
双轨体验ChatBox -> 工作台、工作台 -> 专家页、专家页 -> ChatBox 解释。`dual_track_ux_audit.json` + E2E 截图。专家多 Tab 保留，普通用户无需先进入专家页。
交易边界所有回复、按钮、卡片、报告继续阻断正式买卖、下单和自动交易。`trade_boundary_wording_audit.json`。不得把交易字段、订单创建字段或自动执行字段描述为开放状态。
