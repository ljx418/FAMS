01 / Definition

RRG 到底是什么

Relative Rotation Graph（相对旋转图）把一组标的相对同一基准的趋势与动量放进一张二维图，并用历史尾迹呈现市场领导力如何变化。

ONE SENTENCE

横轴回答“相对趋势强不强”，纵轴回答“这个趋势正在加速还是减速”。

中心点通常标准化为 100 / 100。每个标的当前是一个点，过去若干期形成尾迹；比较必须使用同一基准、同一频率与可比价格口径。

X AXIS

JdK RS-Ratio

衡量相对表现的趋势及其强度。高于 100 表示相对趋势偏强，低于 100 表示偏弱。

asset / common benchmark → normalized trend
Y AXIS

JdK RS-Momentum

衡量 RS-Ratio 的变化动量，通常领先于 RS-Ratio 转向，但不保证趋势一定反转。

momentum of relative trend → normalized

示意图仅解释坐标、方向和尾迹，不代表任何真实标的判断。正式功能必须同时显示基准、数据截止日、价格口径与质量状态。
+ RATIO / + MOMENTUM

领先 Leading

相对趋势强，动量也强；不等于绝对价格一定上涨。

+ RATIO / − MOMENTUM

转弱 Weakening

相对趋势仍强，但动量下降；可能只在右半区内震荡。

− RATIO / − MOMENTUM

落后 Lagging

相对趋势与动量都弱；它仍可能在绝对价格上上涨。

− RATIO / + MOMENTUM

改善 Improving

相对趋势尚弱，但动量改善；是观察候选，不是买点。

三条解释边界：典型路径常呈顺时针，但不保证走完四象限；RRG 关注相对表现而非绝对收益；官方资料明确其不是具有固定规则的交易系统。RRG® / Relative Rotation Graphs® 及 JdK 指标名称属于 RRG Research 的注册商标，未授权自研版本应使用清晰区分的产品命名。

03 / Recommended target

建议对齐成一个“轮动研究工作台”

它不是再加一张漂亮的散点图，而是把“选择比较对象—验证数据可比—观察轮动—回到价格证据”串成一个研究闭环。

目标内：首版必须成立

  • 当前持仓、自选组合或预设集合使用同一基准比较
  • 日频 / 周频切换，尾迹 4–12 期，标的显隐与高亮
  • 当前象限、方向、尾迹速度、排序与选中标的详情
  • 明确展示数据截止日、基准等级、价格口径与缺失原因
  • 结果可追溯到输入序列、公式版本与计算时间

目标外：首版明确不做

  • 把“进入领先象限”直接翻译为买入或加仓建议
  • 自动创建订单、自动调仓或解除任何交易门禁
  • 在没有统一交易日与价格口径时强行比较跨市场资产
  • 把自研近似指标称为 JdK RS-Ratio / RS-Momentum
  • 为了填满图表而隐藏数据不足、陈旧或基准代理状态

05 / Definition of done

目标对齐后，用这些结果判断“做对了”

这不是实施排期，而是产品级验收口径。后续开发计划应从这些结果反推数据、计算、API、前端与验证任务。

A01

语义正确

同一标的、同一输入与公式版本得到稳定结果；页面不混淆 RSI、绝对收益和相对趋势。

A02

可比性可见

基准、频率、复权、币种、共同截止日与数据状态无需点开二级页面即可确认。

A03

缺口不静默

历史不足、日期错位、基准缺失或数据陈旧时，不画误导尾迹，并给出可行动原因。

A04

研究闭环

用户能从全局轮动图选择标的，再回看价格与相对线证据，而不是只看象限颜色。

A05

交互可用

桌面与移动端可操作；标的高亮、显隐、键盘焦点、尾迹控制和空/错状态完整。

A06

边界不漂移

所有输出保持 RESEARCH / OBSERVE / COMPARE，不生成订单或绕过人工交易门禁。

进入开发计划的唯一前置

确认“计算身份、首版资产集合、默认共同基准”三项选择；频率默认周频 12 期，同时保留日频切换。
