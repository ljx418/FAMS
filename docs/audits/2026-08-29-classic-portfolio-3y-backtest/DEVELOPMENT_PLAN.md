# 中国版经典组合三年回测开发计划

- 日期：2026-08-29
- 阶段：实际开发
- 初始资金：100,000 元
- 研究区间：2023-08-29 至 2026-08-28
- 安全边界：只生成 `RESEARCH / OBSERVE / COMPARE / PLAN_DRAFT`，不创建真实订单

## 子阶段

1. 扩展组合定义：全天候、永久组合、60/40、黄金蝴蝶、红利低波60/40。
2. 将回测核心改为显式现金账本、整数手、次日开盘成交、最低佣金、滑点和固定现金收益。
3. 同时运行不调仓、周、半月、月、季强制再平衡以及每日3个百分点偏离触发。
4. API 返回情景矩阵、交易流水、决策日历、频率研究结论和数据真实性审计。
5. 前端在策略回测页展示标的代码、目标权重、频率比较、具体买卖动作及下一决策时间。
6. 使用项目数据服务补齐近三年真实行情，完成后端、接口、前端和真实浏览器端到端验收。

## 决策口径

- 固定现金模型年化 1%，按 ACT/365 逐日复利，内部代码 `CNY_FIXED_1PCT`。
- 前一交易日收盘后决策，下一交易日开盘成交，禁止同日收盘前视。
- ETF 按 100 份整数手；佣金率 0.03%、每笔最低 5 元、滑点 0.05%、ETF 印花税 0。
- 频率不按全样本最高收益直接选择；以最后 12 个月验证期、最大回撤、风险收益和成本稳定性综合判断。
- 数据覆盖不足、价格老化或无法交叉核验时标记 `insufficient`，不得输出确定性有效结论。
