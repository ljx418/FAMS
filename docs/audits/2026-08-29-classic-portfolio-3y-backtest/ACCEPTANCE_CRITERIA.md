# 中国版经典组合三年回测验收标准

## PRD 规格

1. 五个组合均展示具体境内代码和固定权重，且不包含港股、美股、科创板直接交易动作。
2. 六种调仓机制使用相同行情、成本和资金约束完成横向比较。
3. 每笔模拟动作包含决策日、执行日、方向、代码、整数手数量、价格、金额、费用及执行后权重。
4. 现金按固定年化 1%计息，账本每日满足“现金 + 持仓市值 = 组合价值”。
5. 页面明确显示历史收益、最大回撤、波动率、Sharpe、换手、成本、数据截止日和非交易建议边界。
6. 给出下一次人工检查日期；不得连接真实券商或写入真实持仓、交易表。

## 自动化验收

- 合成行情验证次日开盘成交，无同日收盘前视。
- 整数手、最低佣金、现金利息和3个百分点偏离触发均有确定性断言。
- 五组合乘六情景完整返回，所有净值均为有限正数，交易流水资金对账误差不超过 0.01 元。
- 真实三年行情每个标的覆盖率达到 98%；不足时必须真实失败或降级，禁止虚假通过。
- 后端与前端生产构建通过；现有组合回测契约、安全门和相邻页面不回归。
- 真实浏览器能够运行三年研究、查看频率矩阵和至少一条交易流水，控制台无错误。
