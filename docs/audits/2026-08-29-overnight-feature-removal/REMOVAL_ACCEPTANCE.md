# 隔夜强势策略功能下线验收

- 日期：2026-08-29
- 状态：通过
- 决策：基于现有研究未证明策略具有可重复、扣费后交易优势，按用户指示从产品运行面完整下线
- 边界：这是产品下线决定，不将 `data_insufficient` 改写为“数学上永久无效”

## 删除范围

1. 前端删除主导航、React 路由、页面、图表/网格组件、API 客户端、专属样式和运行时验证脚本。
2. 后端删除 `/api/v1/overnight-strategy` 路由、筛选/草案/回测/前向验证/90日网格服务、恢复钩子、数据采集脚本和专属测试入口。
3. 删除 `package.json` 中全部隔夜策略测试及运行命令。
4. 从 Prisma 活动 schema 中移除隔夜策略及其专属分钟数据模型并重新生成客户端。
5. 删除活动 PRD、证据协议和追踪矩阵；历史阶段审计报告继续保留。

## 数据保留与安全边界

- 下线前数据库中没有 `queued` 或 `running` 的隔夜任务，只有 2 个已完成90日实验和22个已完成严格回测操作。
- 没有运行数据库迁移、DROP、DELETE 或资产/持仓/交易写入。
- SQLite 中原有实验物理表和历史记录原样保留，仅作为可追溯档案；新 Prisma 客户端不再暴露这些模型，应用也没有调用入口。
- 真实行情数据目录继续由 `.gitignore` 隔离，防止数百MB研究数据误入源码提交。
