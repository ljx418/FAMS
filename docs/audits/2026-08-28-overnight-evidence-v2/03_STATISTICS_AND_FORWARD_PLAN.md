# 子阶段3：统计证据、冻结样本与前向影子计划

## 验收标准

1. 实现按交易日分块Bootstrap置信区间，固定随机种子可完全复现。
2. 对75组参数/变体执行Reality Check等价的多重比较校正。
3. 实现四态结论，数据不足、样本不足与真正无效不得混淆。
4. 交易决策级要求300笔/24个月、置信区间下界>0、单笔>=0.20%、PF>1.20、回撤<=15%、集中度<=30%、70%窗口为正及双倍成本门槛。
5. 冻结日期与预注册哈希写入运行记录，最终样本不得参与选参。
6. 前向影子运行保存每日信号、模拟成交、规则版本和参数版本；修改规则后重启观察时钟。
7. 前向阶段不创建真实委托，所有交易边界继续为false。

## 详细开发步骤

1. 实现确定性PRNG、分块Bootstrap、多重比较p值、月度集中度和窗口稳定性。
2. 建立证据决策服务，输入数据Manifest、组合变体和前向状态，输出四态结论与逐门禁解释。
3. 扩展回测记录的模式、证据等级、结论、预注册哈希、成本和证据JSON。
4. 新增前向影子运行/观察模型与API服务；只保存研究证据。
5. 让旧回测在缺少新Gold候选时返回 `data_insufficient`，而非沿用旧的单信号晋级。
6. 完成统计、冻结边界、状态机和真实数据阻塞测试。

## 开发前审计

- **重大风险：** 当前真实样本为0笔，统计函数只能用确定性序列验证；真实任务必须输出 `data_insufficient`。
- **重大风险：** 多次查看最终样本会污染结论；运行记录必须保存协议哈希和最终样本锁定状态。
- **重大风险：** 前向观察不足3个月；任何当前运行都只能是 `collecting`，不得标记通过。
- **结论：** 风险通过四态结论、不可变哈希和时间门禁闭环，可进入开发。
