# 子阶段2：组合成交、基线、消融和压力测试计划

## 验收标准

1. 同日候选按冻结排序最多取3只，执行25万元、10%/30%、现金和100股整数手约束。
2. 组合收益按交易日聚合；同日多标的不作为独立统计样本。
3. 入场只能发生在信号完成后的下一分钟且不晚于14:56:50；没有1分钟证据时不得给出正式成交。
4. 参与率超过下一分钟成交量5%、限价未触及、停牌、无量或一字板时不虚构成交。
5. 无法次日退出时顺延至首个可交易时点；支持现金分红调整。
6. 生成完整策略、简单基线、匹配基线、沪深300基线、八步消融和基础/2倍/3倍成本结果。
7. 原有75组参数矩阵兼容，且训练/最终样本边界不可越过。

## 详细开发步骤

1. 把信号输入扩展为排名字段、1分钟成交片段、后续交易状态和公司行为。
2. 实现逐日资本账本与组合分配器，复用线上排名和仓位语义。
3. 重写退出状态机，区分未成交、集合竞价隔离、停牌/跌停顺延、止盈止损和强制退出。
4. 实现基线、消融和成本倍数批量运行接口。
5. 保留旧单信号模拟函数用于兼容测试，但禁止其决定交易决策级结论。
6. 完成确定性、边界、组合约束与未来数据污染测试。

## 开发前审计

- **重大风险：** 当前Gold特征没有1分钟成交片段；正式证据必须阻塞，测试只能使用明确标注的确定性行情序列。
- **重大风险：** 历史公司行为数据尚未覆盖；缺失时不得按未复权价格直接计算跨除权日收益。
- **重大风险：** 当前真实数据只有单日，无法形成次日退出；真实验收应验证阻塞语义，不能声称收益验证通过。
- **结论：** 引擎可以先用确定性边界序列验证并在真实数据上验证阻塞；正式收益结论仍由覆盖门禁控制，无新增致命风险。
