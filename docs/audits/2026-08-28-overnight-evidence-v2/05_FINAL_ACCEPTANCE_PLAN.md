# 子阶段5：最终真实数据E2E与审计包计划

## 验收标准

1. 数据仓、真实免费源、组合执行、统计、前向状态机、真实回测API和前端契约全部复跑通过。
2. 最新真实运行保存 `decision=data_insufficient`，并列出当前真实分母、覆盖率、1分钟和Gold缺口。
3. Prisma schema格式、校验、数据库同步和客户端生成通过。
4. 前端生产构建与浏览器页面复验通过。
5. 全仓后端构建如受不相关用户改动阻塞，必须给出原始错误、影响边界与停止原因，不得标记全部通过。
6. 最终审计汇总软件交付、策略证据、数据采购、前向等待和交易边界五类状态。

## 详细执行顺序

1. 复跑Stage1–4全部隔夜专用测试和真实数据测试。
2. 运行Prisma格式/校验/生成及前后端构建。
3. 查询最新Backtest、Manifest与数据库计数，形成事实快照。
4. 检查Git差异，仅审计本功能文件，不覆盖工作区其他改动。
5. 落盘最终追踪矩阵和自动化停止原因。
