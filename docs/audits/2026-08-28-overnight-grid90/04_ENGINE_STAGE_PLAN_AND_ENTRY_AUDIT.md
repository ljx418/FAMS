# 90 日网格实验：引擎子阶段计划与准入审计

- 状态：准入通过
- 输入：已验收日线、历史股本、5分钟行情、沪深300和第二源抽检报告
- 输出版本：`overnight.grid90.v1`

## 详细开发计划

1. 逐候选事件重建 14:30–14:55 的信号时快照：涨幅、10/20/30日涨停基因、盘中重算量比、盘中换手、市值、VWAP稳定度和相对沪深300强度。
2. 分别生成6种第8步信号，始终保持“信号后下一根且不晚于14:55的5分钟线”成交规则。
3. 训练期只运行前60个交易日的5,832组参数；每天按冻结排序最多选择3只，100股整数手、单票10%、策略30%、5%成交参与率不变。
4. 固定次日10:00退出；若10:00仍一字跌停锁死，则延迟到首次可交易5分钟并使用该根最低价，避免伪造成交。
5. 训练期执行样本、经济、双倍成本、PF、最大回撤、交易日分块Bootstrap和全网格多重比较门禁，只选择唯一参数。
6. 留出30日只评估原始基线和训练唯一候选，不重新排序或调参。
7. 产出信号特征、5,832组训练指标、留出成交和JSON摘要，并保存输入哈希与审计字段。

## 引擎验收标准

- 网格必须恰好5,832组且参数哈希唯一；原始基线必须恰好出现1次。
- 训练/留出必须严格为60/30个交易日。
- 每个日线/股本/分钟/第二源输入文件必须进入指纹；重复运行在指纹不变时必须幂等。
- 信号计算不得引用信号后的成交量、收盘换手或未来基准数据。
- 3%/5%只统计次日10:00前最高价触及率，不改变退出成交价。
- 多重比较未通过时不能选择训练候选；无训练候选时留出集只运行原始基线。
- 即使经济门禁通过也不得返回 `effective`；既存数据阻断项存在时必须返回 `data_insufficient`。
- 四项交易权限必须持续为 `false`。
