# 隔夜强势策略90交易日全网格实验：总计划与准入审计

日期：2026-08-28
实验版本：`overnight.grid90.v1`
原规则版本：`overnight.eight_steps.v1`（冻结，不修改）
状态：准入通过，可进入数据阶段

## 1. 目标与边界

使用真实A股主板数据，在90个信号交易日内验证原始八步法和5,832个受控参数组合。前60日只用于选参，后30日为冻结留出集。所有实验交易固定次日10:00退出；3%/5%只统计10:00前触及率，不提前止盈，也不得表述为收益承诺。

实验只允许研究、观察和人工复核。`formalTradingUnlocked`、`autoTradeUnlocked`、`canCreateOrder`、`orderCreateAllowed`始终为false，不创建真实委托。

## 3. 冻结5,832组参数

| 规则 | 取值 |
|---|---|
| 涨幅 | `[2,5]`、`[3,5]`、`[3,6]`% |
| 涨停回看期 | 10、20、30个完整交易日 |
| 最低量比 | 0.8、1.0、1.2 |
| 换手率 | `[3,10]`、`[5,10]`、`[5,15]`% |
| 总市值 | `[30,200]`、`[51,200]`、`[51,300]`亿元 |
| 分时强度 | VWAP上方比例80%/90% × 最大下破0.3%/0.5%；相对沪深300必须>0 |
| 第8步 | `strict_0_2`、`strict_0_5`、`strict_1_0`、`separate_touch_0_2`、`same_bar_touch_0_2`、`new_high_only` |

组合数固定为 `3×3×3×3×3×4×6=5,832`。原始基线为3%–5%、20日、量比1、换手5%–10%、市值51–200亿元、90%/0.3%、`strict_0_2`。

0.5%和1.0%严格版本的信号带宽与入场限价同步放宽；必须单独标注追价风险。所有版本在信号时重算前七步，信号后只检查下一根且不晚于14:55的5分钟线。100股整数手、单标的10%、策略30%、最多3只、5%分钟参与率和原排序规则不变。

## 4. 收益、选参与结论

- 主结果固定次日10:00退出；停牌、一字跌停或无量时顺延至首次可交易时点，不伪造成交。
- 记录基础/2倍/3倍成本、3%/5%盘中最高触及率、平均值、中位数、胜率、PF、最大回撤和交易日分块Bootstrap。
- 训练候选：至少20笔、10个交易日；基础和双倍成本均值>0；PF>=1.05；最大回撤<=15%；Bootstrap 95%下界>0；5,832组多重比较校正通过。
- 选参排序：Bootstrap下界、平均净收益、PF、交易数、距原始参数距离、参数哈希。只选唯一候选。
- 留出集只允许评估该唯一候选和原始基线。候选至少10笔、8个交易日，且重复训练期经济与统计门禁。
- 即使通过也只能返回`research_candidate`；未通过为`no_supported_variant`；数据门禁失败为`data_insufficient`。不得返回`effective`。

## 5. 分阶段停止条件

1. 数据：全量请求、日期、主键、点时股本、候选历史状态、基准或第二源验收失败时停止。
2. 引擎：组合数不等于5,832、基线不能复现V1、出现未来函数、留出泄漏或虚假成交时停止。
3. API：实验覆盖正式回测、影响人工草案晋级或交易权限变化时停止。
4. 前端：展示确定性收益承诺、隐藏数据不足或无法追溯审计证据时停止。

## 6. 准入审计意见闭环

- 三个月旧实验数据不能直接冒充90交易日；使用独立数据根重新采集。
- 5分钟用于全网格研究；训练选中的唯一候选才进入1分钟留出重放。公共源无完整1分钟覆盖时保持`data_insufficient`。
- 历史ST/停牌仅需覆盖可能形成信号的候选事件，但缺失事件必须剔除并计入覆盖率。
- 5,832组不得在留出集重新排名；前端热力图只展示训练指标。
- 正式V2、90日实验和人工草案查询必须按`evidenceMode`隔离。

结论：没有新增致命或重大未闭环风险，允许进入真实数据阶段。
