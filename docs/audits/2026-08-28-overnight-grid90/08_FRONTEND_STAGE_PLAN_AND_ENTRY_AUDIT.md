# 90 日网格实验：前端子阶段计划与准入审计

- 状态：准入通过
- 输入：已验收API与真实实验记录

## 详细开发计划

1. 在“证据与回测”内增加二级页签：“长期交易决策级证据”与“90日放宽实验”。
2. 90日页首先显示结论摘要：无训练候选、经济结论、不足证据原因和禁止实盘边界。
3. 用60日训练→唯一候选门禁→30日留出的流程图解释防泄漏设计；无候选时明确显示留出只运行基线。
4. 提供训练热力图，默认横轴涨幅、纵轴第8步、指标为成交数；允许切换有限指标，始终显示固定参数和“仅训练”标识。
5. 提供服务端分页参数表，默认可查看有成交组合；显示样本数、活跃日和门禁，避免只展示收益最高值。
6. 展示原始基线留出结果；0笔必须显示“不可估计”，不能显示0%收益。
7. 提供“校验并同步真实实验”按钮和后台进度，不出现买入、下单、有效策略等误导动作。
8. 完成响应式、键盘可用、ARIA标注、前端构建、运行时契约和真实浏览器E2E。

## 验收标准

- 页面真实显示5,832组、1,620个有成交参数组、0训练候选、p=0.9525、基线留出0笔。
- `no_supported_variant` 必须解释为“当前窗口没有受支持参数”，`data_insufficient` 必须解释为“仍不能证明普遍有效或无效”。
- 热力图不得使用留出指标，且必须显示其余固定参数。
- 收益列必须同时展示成交笔数；1笔的收益最高组合不得标记为推荐/最佳。
- 0笔指标显示“不可估计”，不得补0。
- 移动端表格可横向滚动，控件有标签，错误状态不回退演示数据。
- 正式证据页原功能不丢失，回测/前向/取消按钮仍正常。

## 准入审计意见

没有新增致命或重大风险。最主要的内容风险是把“平均收益最高但仅1笔”误读为最佳方案，已通过结论摘要、样本列、门禁标签和禁用推荐措辞转化为强制验收项。
