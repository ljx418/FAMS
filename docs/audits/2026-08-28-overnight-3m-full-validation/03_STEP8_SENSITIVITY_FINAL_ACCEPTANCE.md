# 第8步放宽敏感性实验：最终验收与结论

日期：2026-08-28
原策略状态：未修改
实验结论：`no_supported_relaxation`
推荐放宽幅度：无

## 1. 结论摘要

在2026-05-28至2026-08-27的真实主板数据中，系统独立重算并精确复现115个通过前七步的事件，分布于47个交易日。没有任何预注册的VWAP带宽版本同时满足样本数、75组退出稳健性、基础成本和双倍成本条件，因此不能支持把第8步从0.2%修改为0.5%、1.0%、1.5%或2.0%。

关键判断：

- 仅扩大回踩带宽不是有效修复。0.5%仍为0个信号；1.0%、1.5%、2.0%分别只有1、3、5个信号，且按原PRD `VWAP×1.002` 限价均为0笔成交。
- 完全取消回踩上界、但保留“先创新高、再出现另一根线”的顺序，也只有9个信号、0笔原限价成交。
- 只保留创新高可成交8笔，固定次日10:00成本后平均收益-2.7631%；75组退出规则平均收益全部为负。
- 完全移除第8步可模拟成交105笔，固定次日10:00成本后平均收益-0.6090%；75组退出规则平均收益仍全部为负。
- 因而当前零交易不只是0.2%阈值过窄。更主要的约束来自“尾盘创新高后还要等待独立回踩线”的时间顺序；直接删除该保护条件又没有观察到正收益。

## 4. “放宽多少合适”的回答

本数据不支持任何数值型带宽放宽：

1. 0.5%没有增加信号；
2. 1.0%至2.0%只有1至5个信号，远低于预注册的30笔最低研究样本；
3. 即使不设上界也只有9个信号，说明主要瓶颈不是带宽数字；
4. 删除回踩换取样本后，成本后收益和全部75组退出规则均为负。

因此当前建议是保持原PRD的0.2%不变，但把策略继续标为“仅观察/无可用交易频率”，而不是将0.2%宣传为已证明有效。若要继续研究，应扩大到至少24个月后按同一冻结矩阵重跑；如果另行设计“无需独立回踩线”的新第8步，必须作为新策略版本在未参与本轮选择的窗口前向验证。
