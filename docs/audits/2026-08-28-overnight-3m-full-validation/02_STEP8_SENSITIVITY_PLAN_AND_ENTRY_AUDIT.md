# 第8步放宽敏感性实验：计划与准入审计

日期：2026-08-28
状态：实验矩阵已冻结，原策略与PRD不修改
数据窗口：信号日2026-05-28至2026-08-27；使用既有全量主板日线、历史股本、候选5分钟线及沪深300数据

## 1. 研究问题

回答三个不同问题，结论不得混用：

1. 115个通过前七步的事件，次日开盘、09:45、10:00和10:30的条件收益如何？
2. 仅放宽第8步VWAP回踩上界时，真实信号数、可模拟成交数和成本后收益如何变化？
3. 第8步中究竟是“0.2%带宽”“回踩顺序”还是“必须创新高”造成零交易？

本实验是三个月样本内敏感性分析，不具有正式交易晋级权，也不得把样本内最优参数设为默认策略。

## 2. 冻结实验矩阵

前七步、14:30门禁、异线要求和信号时点重算不变。带宽版本均要求：14:30后已完成5分钟线创新高，随后另一根已完成5分钟线的收盘不低于累计VWAP，且最低价与收盘价均不高于累计VWAP上界。

| 版本 | 第8步定义 | 目的 |
|---|---|---|
| `band_0_2` | `[VWAP, VWAP×1.002]` | PRD原始基线 |
| `band_0_5` | `[VWAP, VWAP×1.005]` | 小幅放宽 |
| `band_1_0` | `[VWAP, VWAP×1.010]` | 中等放宽 |
| `band_1_5` | `[VWAP, VWAP×1.015]` | 较大放宽 |
| `band_2_0` | `[VWAP, VWAP×1.020]` | 激进放宽 |
| `ordered_no_cap` | 创新高后另一根线收盘不低于VWAP，不设上界 | 定位带宽影响 |
| `new_high_only` | 只要求某根通过前七步的线在14:30后创新高 | 定位回踩影响 |
| `first_seven_ablation` | 首次通过前七步即作为事件时点 | 完整移除第8步；覆盖115事件 |

所有可执行研究均在信号后的下一根、且不晚于14:55的5分钟线检查成交，并要求100股整数手的拟成交量不超过该5分钟线成交量的5%。带宽版本的限价仍固定为原PRD的 `VWAP×1.002`，避免在放宽信号的同时抬高买价；若下一根线最低价未触及限价则记为未成交。`new_high_only` 与完全消融版本没有合理的VWAP回踩限价，使用下一根5分钟线开盘作为研究成交价，并明确标为消融而非策略候选。

## 3. 收益口径

### 115事件研究

- 参考买价：首次通过前七步的已完成5分钟线收盘价；这是条件事件研究，不声称可成交。
- 退出：下一交易日开盘、09:45、10:00、10:30。
- 同时报告毛收益与基础成本后净收益。
- 名义资金25,000元/事件，按100股整数手；双边滑点各0.05%，佣金0.025%且每边最低5元，卖出印花税0.05%。

### 第8步版本执行研究

- 入场：信号后下一根可用5分钟线；带宽版执行原始 `VWAP×1.002` 限价。
- 退出：PRD冻结的75组矩阵，即5档止盈、5档止损、3个强制退出时间。
- 每个第8步版本报告75组退出规则下平均净收益的中位数、最好值、最差值及正收益参数占比；“最好值”只用于过拟合风险展示。
- 另报告固定10:00退出的事件级结果，便于各版本同口径比较。
- 不计算真实组合晋级；重叠资金、分钟参与率、逐日ST状态和公司行为覆盖仍是正式证据阻断项。

## 4. 验收标准

1. 前七步事件必须精确复现为115个，否则停止。
2. 所有信号必须在14:30后，且入场不能使用信号线自身或14:57后的数据。
3. 每个收益必须能追溯到证券、信号时间、入场时间、退出时间和源文件。
4. 0笔或缺失收益保持 `null`，不得写成0。
5. 必须同时展示样本数、未成交数、胜率、PF、均值、中位数、最大回撤和双倍成本结果。
6. “合适”的最低研究候选条件预先冻结为：至少30笔可成交样本、75组退出参数的净收益中位数大于0、至少60%的退出参数净收益为正、固定10:00基础与双倍成本平均净收益均大于0。
7. 即便满足上述条件，三个月样本仍只能标记 `research_candidate`；不满足则标记 `no_supported_relaxation`。
8. 四个交易权限必须全部为false，不生成订单。

## 5. 已知限制与审计意见

- 5分钟数据足够做本轮研究回放，但不满足V2正式证据要求的候选1分钟成交验证。
- 当前股票池不是每日点时全市场快照，历史逐日ST身份仍不完整；结论等级不得高于短窗口研究。
- 同一数据用于比较阈值与观察收益，存在多重比较和样本内选择偏差；本轮不能据此确定生产参数。
- 若某档通过最低研究候选条件，下一阶段必须在未参与本次选择的新时间窗口做预注册前向验证。

准入结论：没有新增致命数据错误；允许进入只读、无交易权限的敏感性实验。
