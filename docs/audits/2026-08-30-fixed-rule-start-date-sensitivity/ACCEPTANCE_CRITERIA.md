# 验收标准

日期：2026-08-30

## 核心计算

- 每个经典组合只有一个执行规则，来源为策略注册表，当前均为季度调仓；输出不得存在影响成交的历史择优步骤。
- 主曲线逐交易日提供总资产、人民币盈亏、累计收益、回撤、现金及各成分实际权重；权重合计误差不超过 0.05 个百分点。
- 主交易台账可用现金流逐笔复算，交易日期不得早于实际起点或晚于数据截止日。
- 每周起点必须是该 ISO 周的第一个共同交易日。
- 逐策略指标为区间最高浮盈、年化收益和最大回撤；少于 20 个交易日时年化收益为空并标记 insufficient。
- 横截面指标逐起点严格等于所选策略的最高期末收益、期末收益算术平均和最差最大回撤。

## 数据与持久化

- 默认真实运行：五个经典组合、100,000 元、2023-08-29 起、最新已核验共同交易日止。
- 价格覆盖率不低于 98%，腾讯未复权收盘价交叉核验通过，分红只使用已审计官方事件。
- Operation 保存主结果、交易台账和起投敏感性三个 artifact；重载后的输入、曲线、交易和指标与首次响应一致。
- 数据不足、缺少共同日期或固定规则不受引擎支持时明确返回 blocked/insufficient，不插值或静默降级。

## 前端与安全

- 图一支持总资产、累计盈亏和实际权重三种视图；图二支持逐策略和横截面两种口径。
- 策略选择、图例显隐和颜色在两图一致；点击图二有效点可把对应起点带入图一。
- 页面刷新后能够从历史运行重新打开已保存结果。
- 正式交易、自动交易、真实持仓修改和创建订单全部保持关闭。
- 前后端构建、单元/契约测试和真实浏览器 E2E 全部通过，控制台错误为 0。
