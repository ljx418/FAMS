# 入口审计意见

日期：2026-08-30

## 基线事实

- 现有页面已经支持日期区间、10 万元默认资金、五个经典组合、曲线与优选场景交易流水。
- 现有场景引擎内部计算总资产，但返回曲线剥离了绝对资产值，也没有每日实际权重。
- 现有 `classicPortfolioStudy` 会运行六种规则并产生 `preferredScenarioId`，不符合本阶段“先冻结规则、后观察结果”的要求。
- 现有 Operation 已保存完整结果及 22 项 artifact，可复用，无需新增 Prisma 模型。

## 重大风险及闭环

1. **样本内择优/未来函数**：新建 `fixedRuleStudy` 路径，只读取策略注册表频率；旧研究结果保留兼容但新页面不请求、不展示。
2. **滚动结果体积失控**：周度敏感性只保存汇总点，主起点才保存全量曲线和流水。
3. **跨策略比较口径不一致**：规则和策略版本随请求冻结；横截面只比较同一实际结束日、同一初始资金和同一成本模型。
4. **短持有期年化误导**：少于 20 个共同交易日不计算年化，UI 明确显示样本不足。
5. **数据截止日误报**：服务端从共同日期解析实际结束日，页面不把周末或未收盘自然日冒充交易日。
6. **旧客户端兼容**：新增字段和历史接口采用 additive 方式，不删除旧 `classicPortfolioStudy` 协议。

## 准入结论

所有致命或重大风险均已有明确闭环方案；允许进入固定规则引擎开发。若真实数据核验失败或新路径仍依赖 `preferredScenario`，必须停止并退回计划阶段。
