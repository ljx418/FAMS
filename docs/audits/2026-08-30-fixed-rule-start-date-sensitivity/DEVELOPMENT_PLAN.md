# 固定规则组合回测与起投日期敏感性开发计划

日期：2026-08-30

## 目标

- 五个经典组合按策略注册表中预先确定的季度调仓规则运行，不按历史表现择优。
- 默认初始资金 100,000 元；主回测保存完整交易、资金盈亏、回撤和实际权重曲线。
- 从用户指定的最早起点开始，按每周首个共同交易日计算到最新已核验交易日的起投敏感性。
- 前端提供两张联动图：指定起点的资金/权重曲线，以及逐策略与横截面的起投敏感性曲线。
- 结果通过既有 Operation 与 artifact 持久化，可在刷新页面后恢复；不修改真实持仓或创建订单。

## 子阶段

1. 固定规则引擎：扩展场景曲线的资产、盈亏和权重快照，新增固定规则研究服务和每周起点汇总。
2. API 与持久化：增加 fixedRuleStudy、三个独立 artifact 和按用户读取历史运行的接口。
3. 页面：移除经典组合工作流中的“优选规则”展示，增加双图、共享策略显隐、点选下钻和历史运行恢复。
4. 验收：单元、类型构建、API 契约、真实数据、Operation 重载一致性和浏览器 E2E。
5. 交付：使用 2023-08-29 至最新共同交易日、10 万元和五个经典组合运行一次并保存。

## 实现约束

- 主工作流只执行 `registry_fixed`，不调用 `preferredScenario`，不根据收益改变规则。
- 交易仍按前收盘决策、下一交易日开盘成交、100 份整数手、0.03% 佣金、最低 5 元、0.05% 滑点、分红再投资和现金年化 1%。
- 起投敏感性只持久化每周汇总点；完整日线与交易台账只保存主起点，避免 Operation 无界膨胀。
- “到现在”解析为不晚于当前自然日的最新已核验共同交易日。
- 保持 `ADD / REDUCE / ORDER_CREATE / AUTO_TRADE` 禁止状态。
