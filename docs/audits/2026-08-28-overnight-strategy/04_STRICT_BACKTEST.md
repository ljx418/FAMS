# 子阶段 4：严格 5 分钟滚动样本外回测审计

## 开发前验收标准

1. 回测只接受真实 5 分钟数据与 `publishedAt <= signalAt` 的股本事实，日线代理不得进入执行引擎。
2. 次日退出支持跳空、同线止损优先、止盈、止损和强制退出，并完整计入双边滑点、佣金最低5元及卖出印花税。
3. 12个月训练/3个月测试窗口严格隔离；参数只在训练集选择，测试集不反向参与选择。
4. 默认三年全主板任务使用 Operation/OperationTask，具备进度、取消、失败和重启恢复状态。
5. 分钟/股本覆盖低于90%、样本外不足12个月或100笔时一律 `insufficient`。
6. 晋级必须同时满足正期望、PF>1.1、最大回撤≤15%、单月利润贡献≤30%。

## 详细开发计划

1. 实现执行成本、次日退出和参数矩阵纯引擎。
2. 实现滚动窗口切分、训练选择、测试汇总、回撤和月度集中度。
3. 实现异步回测记录、Operation 任务、取消检查和启动恢复。
4. 从独立分钟表与时间点股本表构建输入；覆盖不足时生成可审计的不足报告。
5. 增加执行顺序、成本、无前视窗口、晋级/拒绝测试。

## 开发前审计意见

- **重大风险（已闭环）**：三年全市场 5 分钟原始数据体量不适合一次性驻留内存；Operation 按任务分段，最终引擎只读取已落盘的候选日特征和证据。
- **重大风险（已闭环）**：当前本地库尚无三年分钟覆盖；首轮真实验收预期应为 `insufficient`，这不是失败伪装，页面必须展示缺口并禁止晋级。
- **重大风险（已闭环）**：训练与测试混用会产生前视；窗口对象分别保存 train/test 边界和当期选参。
- **重大风险（已闭环）**：全市场长任务可能跨进程；OperationTask 保存幂等任务状态，启动时仅恢复未完成的隔夜回测。

结论：无新增致命或重大未闭环意见，可以进入子阶段 4 开发。

## 完成后验收与 PRD 检视

- 纯引擎验证通过：75组参数矩阵、跳空止损、同线止损优先、强制退出、双边滑点/佣金/印花税和12/3滚动窗口均有确定性测试。
- 真实库门禁验证通过：回测 `41826245-172a-4bcc-84c7-228c9ac110a4` 使用真实独立5分钟表，明确记录 `dailyProxyUsed=false`。
- 当前真实覆盖结论为分钟线 `0.13%`、历史时间点股本 `0.00%`、样本外 `0笔/0个月`，因此正确保持 `insufficient`；没有虚报三年全市场回测。
- 默认无代码输入时会以本地规范 A 股身份清单的完整主板集合做覆盖率分母，不能用已缓存的少量代码冒充全市场。
- 回测建立独立 Operation/OperationTask，支持任务中心取消检查和服务启动恢复。

**审计结论：通过。** 当前数据不足属于真实风险披露，不构成虚假验收；功能与门禁可以进入页面开发。
