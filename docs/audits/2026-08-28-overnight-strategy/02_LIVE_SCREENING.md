# 子阶段 2：八步实时筛选审计

## 开发前验收标准

1. 八步规则均为纯函数可验证，含全部闭区间、时间边界和缺失数据行为。
2. 实时扫描从真实公开行情读取全市场快照；只为通过前置门槛的少量标的拉取分时数据。
3. 行情源和系统重算量比同时保留，偏差超过 5% 阻断。
4. 第 7、8 步只用已完成 5 分钟线；同根 K 线不得同时视为新高和回踩。
5. API 返回数据时间、提供方、证据、置信度、质量阻断和交易边界信封。
6. 14:30–14:56:50 之外扫描仍可运行，但必须是 `preview_only`。

## 详细开发计划

1. 实现规则引擎、1m→5m 聚合、累计 VWAP、相对强度和入场状态机。
2. 实现 Eastmoney 快照/分时适配器与 BaoStock 日线/股本适配器，失败时明确降级，不伪造数据。
3. 实现扫描服务、持久化和概览/数据就绪接口。
4. 增加规则契约测试和真实数据冒烟测试。

## 开发前审计意见

- **重大风险（已闭环）**：全市场逐只拉分时会产生不可接受的延迟；先用快照完成板块、涨幅、量比、换手、市值预筛，再拉候选分时。
- **重大风险（已闭环）**：实时快照市值不能用于历史回测；实时扫描可作为展示交叉校验，回测仍只用时间点股本。
- **重大风险（已闭环）**：非交易日或非门禁时间不能被误解为可买；强制返回 `preview_only`，即使八步技术条件均通过也不可行动。
- **重大风险（已闭环）**：数据源不可用时禁止填充演示候选；空结果必须附数据质量原因。

结论：无新增致命或重大未闭环意见，可以进入子阶段 2 开发。

## 完成后验收与 PRD 检视

- 规则契约测试通过：时间门禁首尾秒、主板代码、量比公式、20日涨停基因、VWAP稳定性、新高/回踩异线约束和最小价格单位均已覆盖。
- 真实数据冒烟通过：腾讯/东方财富公开行情返回 2 只真实证券快照、30 根日线、241 根分钟线及沪深300实时报价；实际扫描记录为 `cfe2333e-369a-4dca-813e-8816b513adb0`。
- 真实数据时间为 `2026-08-28T07:59:40.771Z`，运行时已超过可行动窗口，因此正确返回 `preview_only`，没有伪造可买状态。
- 所有响应继续返回四个关闭的交易边界字段；缺失、日期不匹配与双量比偏差均进入 blockers。
- 原始/规范 5 分钟 OHLCV、累计 VWAP、来源和散列均已写入独立分钟表。

**审计结论：通过。** 未发现虚假验收或重大 PRD 偏差，可进入子阶段 3。
