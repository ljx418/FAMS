# RRG 多市场自选 V1 开发与验收审计

日期：2026-08-27
结论：通过自动化开发验收，可进入人类页面审查。

## 开发前验收标准

1. 持仓与自选统一展示且不重复。
2. 三市场代码规范、独立基准和价格口径准确。
3. 显隐仅属于前端展示状态，隐藏项不参与自动刷新。
4. 删除只清理用户专属 RRG 派生数据，保留共享行情、同行用户和持仓。
5. 样本门槛和数据老化必须显式，严禁对长鑫科技短历史生成虚假坐标。
6. AI ETF、半导体 ETF、长鑫科技以真实数据跑完正式验证；HK/US至少各一组真实数据复算。

## 已知非致命限制

- 港美股备用源为单一来源，不能等同于双源共识行情；系统明确降低置信度并显示警告。
- 显隐存储在当前浏览器的 `localStorage`，不会跨浏览器同步，这是“前端仅管理显示/隐藏”规格的有意设计。
- 行情状态相对同市场基准交易日计算；没有新基准数据时状态为待校验，不猜测交易日。
