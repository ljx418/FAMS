# target-architecture-gap.drawio 摘要

更新时间：2026-07-14T00:00:00+08:00

## 总体结论

当前 drawio 已重构为“下一阶段开发目标路线图”版本，共 8 页，未超过 8 页限制。本版优先回答“下一阶段到底要做什么”：把 FAMS 从研究级可用工作台推进到正式交易前置评审 ready，但仍不解锁正式交易、不下单、不自动交易。

## 8 页结构

1. **下一阶段开发目标**：一句话目标、当前已有能力、当前问题、下一阶段用户和审计价值。
2. **当前架构与目标架构差异**：当前前端/API/数据/回测/交易边界如何演进到数据治理、benchmark、formal validation 和 release gate。
3. **数据可信与字段级治理**：正式 provider、research fallback、字段级 evidenceRefs 和 freshness。
4. **回测可信与模型验证**：benchmark 资格、total return、OOS、walk-forward、参数敏感性和分组稳定性。
5. **人工计划与执行隔离**：人工签核、订单意图阻断、paper/sandbox 隔离和 release gate。
6. **用户场景与验收路径**：真实资产导入、组合对比、红利低波、人工计划草案、审计复核五条路径。
7. **开发计划与审计产物**：S0-S8 顺序、每阶段产物和打回规则。
8. **出门条件与人工审查**：能声明什么、不能声明什么、人工审查入口和打回条件。

## 当前可以声明

```text
drawioPageCount<=8
drawioNextStageGoalReadable=true
drawioCurrentTargetRelationReady=true
nextStagePlanActionable=true
expertModuleTabsPreserved=true
formalTradingUnlocked=false
autoTradeUnlocked=false
canCreateOrder=false
orderCreateAllowed=false
```

## 当前不能声明

```text
formalTradingReleaseReady 不得为 true
formalTradingUnlocked 不得为 true
autoTradeUnlocked 不得为 true
canCreateOrder 不得为 true
orderCreateAllowed 不得为 true
officialBenchmarkCertified 不得为 true
formalValidationPassed 不得为 true
```

## 人工审查重点

- 第 1 页是否能直接看懂下一阶段开发目标。
- 第 2 页是否能看懂当前架构与目标架构关系。
- 第 6 页是否有用户场景、操作路径和验收结果。
- 第 7 页是否能指导自动化开发顺序。
- 第 8 页是否清楚说明出门条件和正式交易锁定边界。
