## 总体结论

当前 drawio 已按 UX-F7 v3 实现结果同步为 8 页，未超过 8 页限制。图中使用中文书写，并用颜色表达实体状态：

- 灰色：已开发基础。
- 黄色：本阶段已修改 / 已收口。
- 橘黄：本阶段已新增 / 已补齐。
- 红色：硬边界。
- 蓝色 / 绿色：用户路径、目标体验和验收结果。

本轮 drawio 的重点是把 UX-F7 从流程图式说明升级为目标页面展示形态驱动的实现地图，并同步到本轮实际实现。v3 目标页面 PNG 位于 `docs/prototypes/ux-f7-assets/v3/`，本轮代码实现已用实际截图与这些目标展示形态对照验收。

## 页面结构

1. **阶段目标与目标体验**：说明普通用户、资深用户、审计用户三类目标体验，以及 UX-F7 出门状态和交易硬边界。
2. **当前架构与目标架构差异**：已重排为四层架构映射，分别是“存量前端入口”“存量 API / 服务 / 数据证据”“UX-F7 改造层”“目标体验与验收产物”。这一页不再只做当前/目标摘要，而是逐项标明 `AppLayout.tsx / Dashboard.tsx / FamsChatBox.tsx / Assets.tsx / Backtest.tsx / DividendLowVol.tsx / Operations.tsx / Analysis.tsx`、`chat.ts / asset.ts / template.ts`、`PortfolioBacktestEngine / dividendLowVolStrategyService / Operation artifact` 如何被复用、修改或补齐，并最终对应到普通用户工作台、资产本地账本、专家模式保留和验收证据。
3. **前端目标页面与模块关系**：绑定 Dashboard、ChatBox、Assets、Backtest、DividendLowVol、Operations、Mobile Shell、组件样式板与对应 v3 目标图。
4. **ChatBox 工作台 专家页双轨**：说明 ChatBox 是第一入口但不替代专家多 Tab，并展示 ChatBox -> 工作台 -> 专家页 -> ChatBox 解释闭环。
5. **资产 Excel 本地账本路径**：展示模板下载、上传解析、预览校验、确认导入、导出复核、Dashboard 刷新和资产审计链路。
6. **策略 回测 任务审计联动**：展示组合回测、红利低波、任务审计共享服务、数据可信、artifact 和 trade gate。
7. **开发及验收计划**：按视觉系统、Dashboard/ChatBox、资产 Excel、专家页、移动端、专项审计、E2E 出门展示已完成的实现顺序与验收证据。
8. **里程碑 出门条件 硬边界**：定义文档出门、代码实现、验收产物、UX-F7 出门条件和仍锁定事项，并标明本阶段已通过自动化验收。
